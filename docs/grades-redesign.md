# 成绩页重做方案（v0.2.27 现状）

Date: 2026-11-19
依据: `material-3` + `frontend-design` 两个技能；现状证据来自 `GradesScreen.kt` 与真机截图
状态: **只出方案，不动代码**

---

## 0. 一句话

现在的成绩页是"一个 GPA 大数字卡 + 一列长得一样的行"，它回答的是"我多少分"，
但成绩单真正要回答的是"**哪些学分拿到了、拿得好不好、还差什么**"。
所以重做的方向不是把大数字做得更大，而是把它做成一张**学期成绩单**。

---

## 1. 现状诊断

### 1.1 结构问题

| 位置 | 现状 | 问题 |
|---|---|---|
| 顶部 | 最多 8 个学期胶囊横滑 | 一学期时整行消失；多于 4 个学期要盲滑；看不到"当前学期" |
| 主体 | `PrismMetricCard`，`primaryContainer` 整卡填充，40sp 大数字 | 典型的"大数字 + 小标签"默认版式；饱和容器当整卡底，和刚才在生活页改掉的是同一个毛病 |
| 切换 | 有效/原始 两个 `PrismChip` | 这是**模式**不是筛选，用 chip 表达层级过高，且和上面学期胶囊长得一样 |
| 列表 | 每行 `IconBadge(Grade)` | 每门课都是同一个奖章图标 —— 零信息量的装饰 |
| 行副标题 | `"92 分 · 4.0 绩点 · 5.0 学分"` | 中文里塞英文单位；空值时出现 "— 绩点"、" ? 学分" |
| 底部 | 一行免责声明 | 信息密度低，但这是合规要求，保留 |

### 1.2 数据其实比现在展示的多

`Grade` 里有 `courseCode / credits / score / gpa / category`，现在只用了 3 个字段：

- **`category`（课程类别）完全没展示** —— 必修/选修/通识混在一个列表里，看不出学分结构。
- **等级制成绩没处理** —— 五级制（优秀/良好/中等/及格/不及格）的 `score` 不是数字，
  现在会显示成"优秀 分"，且 `computeGpa` 直接跳过，GPA 偏低。
- **学分没有汇总口径** —— 只显示"已修 N 门课程"，没有总学分/本学期学分。

### 1.3 视觉问题

- GPA 卡是 `primaryContainer` 实底，整页最重的一块色给了一个**派生数字**；
  真正有信息量的课程列表反而是最轻的白底列表。
- 所有分数用同一种灰，92 分和 61 分在扫视时无法区分。
- 数字没有对齐基线，`GPA` 与 `加权平均` 字号不同却并排，读数时眼睛要来回跳。

## 2. 设计计划

### 2.1 核心概念：成绩单，不是仪表盘

成绩单（transcript）这个物件有自己的视觉语言：**刻度、账本、等级**。
三个元素刚好对应三件学生真正关心的事：

1. **刻度** —— 我在 4.0 制的哪一格上（保研线/及格线在哪）。
2. **账本** —— 学分进了多少、还差多少。
3. **等级** —— 这门课属于哪一档，哪些挂了。

所以新版的主视觉是**绩点尺（GPA ruler）**，不是大数字卡。这是这个页面唯一"敢花"的地方，
其余部分全部安静：白卡、细分隔线、等宽数字。

### 2.2 色彩

不做五色彩虹（课表刚把彩虹删掉，成绩页不能又加回来）。等级色只用 4 个语义位：

| 等级 | 分数段 | 颜色 role | 说明 |
|---|---|---|---|
| 优秀 | ≥90 | `primary` | 页面主色，只给最高档 |
| 良好 | 80–89 | `tertiary` | 与主色区分但同强度 |
| 中等 / 及格 | 60–79 | `onSurfaceVariant`（两档用 0.72/1.0 区分） | 中性，不抢眼 |
| 不及格 | <60 | `error` | 唯一允许的警示色 |

基础面仍是 prism 的四级：Page `surfaceContainerHigh` / Card 纯白 / Block `surfaceContainer` / Inset `surfaceContainerHighest`。
**没有新的十六进制色值**，全部走 `MaterialTheme.colorScheme`，跟着主题预设走。

### 2.3 字体

沿用 `PrismType`，不引入新字族（CJK 字体问题另案处理）：

| 角色 | 样式 | 用在哪 |
|---|---|---|
| 尺上读数 | `Display` 40/44 w700 + tnum | 只出现一次，就是 GPA 数字 |
| 尺标签 | `Caption2` 11/14 | 0 / 3.0 / 3.5 / 4.0 刻度 |
| 账本数字 | `MetricSmall` 20/24 w600 + tnum | 学分、门数 |
| 课程名 | `ListTitle` 17/22 w400 | 列表主文本 |
| 课程元信息 | `Footnote` 13/18 | 学分·类别·绩点 |
| 分数 | `TitleLarge` 20/24 w600 + tnum | 每行右侧，右对齐 |

数字全部 `fontFeatureSettings = "tnum"`，保证一列分数上下对齐。

### 2.4 版式

```
A. 成绩单（推荐）
┌ 成绩 ─────────────────── 分享 ┐
│ 2026-2027 学年第一学期      ▾ │  ← 一行，点击开 Sheet 选学期
├───────────────────────────────┤
│  3.42            加权 84.6     │  ← 尺读数：左大右小
│  0 ┄┄较差┄┄┄●┄┄中等┄┄┄┄优秀┄ 4.0│  ← 三档色带，● 在 3.42
│                                │
├───────────────────────────────┤
│  46.5 学分   18 门   4 门优秀  │  ← 账本一行，等宽数字
├───────────────────────────────┤
│  必修                      12 门│
│  ▍高等数学                92   │  ← 左色标=等级，右侧只放分数
│    5.0 学分 · 4.0 绩点 · 优秀  │
│  ▍大学物理                78   │
│    3.5 学分 · 3.0 绩点 · 中等  │
│  选修                       4 门│
│  ...                           │
├───────────────────────────────┤
│  成绩分布  ████▆▆▆▃▃          │  ← 按学分加权的档位条
│  以教务系统为准                │
└───────────────────────────────┘

B. 学期时间轴（备选，适合"看趋势"）
每个学期一段：左侧学期名 + 右侧 GPA/学分，点开进 A 的详情。
问题是手机上垂直距离太长，且和"课表按周翻页"的心智重复。

C. 每学期一张卡（备选）
网格排列，信息量大但每张卡都要重复一次尺/账本，扫视成本高。
```

**对齐**：整体左对齐；数字列右对齐（分数、绩点、学分都靠右形成一条竖线）；
等级色标固定在行首 3dp，和课表的课程块左色标呼应。

### 2.5 原则（判断标准）

1. **派生数字不做主角**：GPA 只以"尺上的指针"出现一次，不再单独占一张饱和卡。
2. **颜色只在有意义的地方出现**：等级色 + 不及格的 error，其余全中性。
3. **一屏说清三件事**：我在哪（尺）、我修了多少（账本）、我哪门差（列表 + 分布）。
4. **一个动效**：只有指针落位那一下。

## 3. 自查：这个方案有没有掉进默认套路

按 frontend-design 的"AI 设计常见特征"逐条对：

| 默认特征 | 本方案 | 处理 |
|---|---|---|
| 大数字 + 小标签 + 渐变强调 | 尺读数确实是数字，但它**挂在刻度上**，有位置含义；没有渐变、没有整卡饱和底 | 保留数字，改写形式 |
| 所有卡片同一个圆角 + 同一个阴影 | 只有尺卡和列表两种容器，且列表用 `PrismGroupedList`（整组一个圆角） | 保留 |
| 每段都有 eyebrow 小标签 | 只在"必修/选修"分组头出现，且它是真分组 | 保留 |
| 中黑点连接元信息（A · B · C） | 行内确实用 `·` 连接"学分/绩点" | 只在行内用一处，不用于标题 |
| 编号 01/02/03 | 无 | — |
| 五个彩色 chip | 只有等级色 4 档，且只用在 3dp 色标 | 已收敛 |

**改掉的一处**：初稿里右列是"92 A"（分数 + 拉丁等级），
但中文成绩单的等级是"优/良/中/及格/不及格"，用 A/B/C 是生硬的翻译。
改成：右列只放分数，等级文字放进元信息行（"5.0 学分 · 优秀"），色标只做辅助。

## 4. 方案 A 细节

### 4.1 学期行（一行，两个控件）

```
2026-2027 学年第一学期  ▾            有效成绩 ⇄
```

- 左：学期名 + ▾，点击开 `PrismSnapSheet`，列出全部学期（当前学期带 `现在` 标记）。
  比横滑胶囊好在：学期数不限、能直接看到"当前"，一学期时也不会空出一整行。
- 右：口径切换，`PrismTextButton`，文案在"有效成绩 / 原始成绩"之间切换，点一次换一次，带触感。
  它是次要模式，不该和学期选择同级。

### 4.2 绩点尺（页面唯一的高光）

```
  3.42                      加权 84.6
  0 ────────●───────────────── 4.0
    └─较差─┘└──中等──┘└──优秀──┘
```

- **不画及格线、不画保研线**：学校没有统一的保研线，写死会误导；及格与否在列表里用文字说，不在尺上判。
- 尺子左低右高，刻度 0 → 4.0，按等分切三段：`较差`（0–1.33）、`中等`（1.33–2.67）、`优秀`（2.67–4.0）。
  三段只在尺线下方用 `Caption2` 标一次，段与段之间不画竖线；色带用同一中性色（`onSurface` 0.06/0.09/0.12）
  由浅到深表示"从差到好"，**不用红绿**——绩点不是告警。
- 分档阈值写成常量 `GPA_BAND_BANDS = 1.33f / 2.67f`，将来学校改口径只改这两个数。
- 指针：`primary` 实心点 12dp + 2dp 竖线，落位用 spring(1f, 420)，只在进入/切换学期时动一次。
- 读数：`Display` 40sp w700 tnum，左侧；右侧"加权 84.6"用 `Subhead`，与读数基线对齐。
- 无数据时：三档色带保留，指针隐藏，读数显示 `—`，并显示"登录教务后显示"。

### 4.3 学分账本（一行，不占卡）

```
46.5 学分        18 门        4 门优秀
```

- 三个等宽数字 `MetricSmall` 20/24 w600，下面 `Caption2` 标签。
- 等分三列（`Row` + `weight(1f)`），不加容器、不加分隔线 —— 它是一行摘要，不是三张卡。

### 4.4 课程列表（按类别分组）

```
必修                              12 门
┌────────────────────────────────────┐
│▍ 高等数学                      92 │
│  5.0 学分 · 4.0 绩点 · 优秀        │
├────────────────────────────────────┤
│▍ 大学物理                      78 │
│  3.5 学分 · 3.0 绩点 · 中等        │
└────────────────────────────────────┘
选修                               4 门
```

- 组头：`SectionHeader`（17/22 w500，onSurface）+ 右侧门数（`Footnote`，onSurfaceVariant）。
- 行：`PrismRow`，`leading` = 3dp×36dp 竖色标（等级色，圆角 2dp），**不再用统一奖章图标**。
- 右列：分数 `TitleLarge` 20/24 w600 tnum，右对齐；挂科用 `error`。
- 元信息：`学分 · 绩点 · 等级`，空值直接省略而不是显示 "—"。
- 分组来源：`category`；为空或全空时退回单组"全部课程"，不出现空组头。
- 组内排序：分数降序（挂科自然落底），同分按学分降序。

### 4.5 成绩分布条

```
成绩分布
████████████▆▆▆▆▃▃▁
优 18.5    良 16.0   中 9.0   及 3.0   不及 0
```

- 一条 8dp 高的堆叠条，按**学分**加权而不是门数（学分才代表学业体量）。
- 每段颜色同等级色，段间留 2dp 白缝（不用描边）。
- 下方一行图例：等级 + 学分，`Caption2`。
- 全 0 段不画，避免一条全是灰线。

### 4.6 状态

| 状态 | 表现 |
|---|---|
| 加载 | 尺卡骨架（线 + 无指针）+ 账本三个灰块 + 2 组列表骨架；不要整页转圈 |
| 未绑定 | 空态 72dp 圆底图标 + "登录教务后查看成绩" + 主按钮"去教务登录" |
| 本学期无成绩 | "本学期还没有成绩" + "成绩一般在考后两周内发布"（不说"暂无数据"） |
| 失败 | 错误说明 + 重试 + 若有缓存则显示"显示的是 11-19 14:02 的缓存" |
| 缓存 | 页头副标题第二行加"缓存于 14:02"，和课表页头一致 |

### 4.7 动效（克制清单）

- 进入：尺指针从 0 落位（spring 1f/420，约 300ms）；数字 `PrismAnimatedText` 已有位移。
- 切学期：内容 `fadeOut(90) + fadeIn(210)`，指针重新落位；不做横向滑动（那是课表翻周的语义）。
- 切口径：只做颜色/数字过渡 180ms，不移动布局。
- 不做：行 stagger、卡片 hover、分布条逐段生长。

### 4.8 无障碍

- 尺：`contentDescription = "绩点 3.42，满分 4.0，位于及格线与保研线之间"`。
- 行：朗读"高等数学，92 分，优秀，5.0 学分"——等级必须**有文字**，不能只靠颜色。
- 分数列右对齐但语义顺序仍是"课名 → 分数 → 元信息"，不因视觉顺序打乱。
- 所有可点区域 ≥48dp；挂科的红色同时有文字"不及格"。

## 5. 数据口径（要改的地方，不是画法）

1. **等级制成绩**：`score` 可能是"优秀/良好/中等/及格/不及格/合格/不合格/通过/缺考"。
   需要一个 `GradeBand` 枚举 + `parseScore()`，把等级映射到 4.0 制（优 4.0 / 良 3.0 / 中 2.0 / 及格 1.0 / 不及格 0）。
2. **`computeGpa` 改造**：现在 `score.toDoubleOrNull()` 失败就跳过整门课，导致等级制课程**学分和绩点都不计入**。
   改成"有 `gpa` 用 `gpa`，否则按等级换算，都没有才跳过"，并在 UI 上标注"N 门未计入"。
3. **学分缺失**：`credits` 为空时不计入总学分，行内不显示" 学分"。
4. **缺考/缓考**：不计入 GPA，但保留在列表里并标注。
