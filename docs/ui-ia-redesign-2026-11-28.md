- 日期：2026-11-28
- 范围：只重排**入口层级、分区归属与设置结构**，并补齐学习通在账号体系里的位置；不新增、不删减任何功能，不改协议与数据流
- 上一轮：`docs/ux-heuristic-audit-2026-11-28.md`（原则层面：状态可见性、容错、帮助入口），本轮处理它没覆盖的**归属问题**

## 归属规则（这次重排的依据）

1. **同一页内不重复**：一个页面里不出现两个通往同一目的地的入口；跨页面的**高频快捷入口**（今天页标题栏的提醒铃铛、我的页的提醒中心行）与设置里的同项目的是「就近入口」，不算多出一层。
2. **按数据来源划归**：教务系统提供的数据（课表、成绩、考试、学籍、教材、**空闲教室**）归「教务」；学习通提供的（作业、通知）单独成组，不混进「教务事务」；缴费类服务（洗浴、电费）归「生活」。
3. **我的 = 账号**，**设置 = 偏好**。账号状态、体检、凭证只在「我的 → 凭证中心」这条线上；帮助、关于、隐私只在「设置」里。
4. **分区只为"能一起改的事"存在**：一个分区至少两条、或一条但带明确状态摘要（如课表设置的当前作息）。

## 新的信息架构

### 五个 tab（不变）

`今天 / 课表 / 教务 / 生活 / 我的`

### 今天

时间轴视角，保持：下一节课倒计时、今日课程、待办（作业 / 考试 / 评教 / 低电费）、生活状态卡。

### 课表

周视图 + 标题栏「课表设置」+ 课程详情。不变。

### 教务（教务系统 + 学习通）

```
学期卡（当前学期 · 本周 N 节课 → 课表）
常用功能      成绩 / 考试 / 选课 / 评教
学习通        作业清单（未交 N 条 · 最近截止）→ 学习通作业
教务事务      学籍档案 / 教材确认 / 教务通知 / 全部教务事务
最近通知      最近 3 条
```

- 学习通从「教务事务」上移为独立分组：它是另一个平台，入口描述写清"未交 / 截止"，而不是一句"未交清单"。
- 「空闲教室」从教务首页与生活页移出，唯一主入口保留在「教务事务」（数据来自教务，事务列表里已有一项）。

### 生活（校园服务）

```
洗浴（区域 · 空闲 · 排队）
电费（房间 · 余额 · 预计可用天数 · 低余额告警）
```

洗浴 / 电费两张状态卡保留；移除与教务重复的「空闲教室」入口卡。

### 我的（账号）

```
欢迎卡（学院 · 学号 · 已保存 N / 4 个平台账号）
平台账号   教务 / 学习通 / 洗浴 / 电费   → 凭证中心
           检查全部账号（行内按钮 + 转圈，结果直接写回四行的状态）
应用       提醒中心 / 设置
```

- 四个平台一行一个，行尾状态徽标同时承担"是否绑定"和"体检结论"（未绑定 / 正常 / 登录失效 / 暂不可用）。
- 取消原来独立的「账号检查」大卡：体检变成「平台账号」分组的行内动作，结果落在同一组里，不再另起一块。

### 凭证中心（账号的唯一入口）

```
四张平台卡（教务 / 学习通 / 洗浴 / 电费）
  标题 · 状态徽标 · 脱敏账号 · 用途 · 登录 / 重新登录 / 退出
账号体检  检查全部账号按钮 + 逐平台结论（含失败原因）
全部退出（四个平台一起退出）
```

- 学习通卡：账号脱敏（`3****4`）、"只读作业同步，不代提交"、登录走现有 `HomeworkLoginScreen`。
- 「全部退出」和「设置 → 隐私与安全 → 清除全部数据」都要退出学习通。

### 设置（偏好）

```
外观          主题模式（跟随系统 / 浅色 / 深色）· 主题色 · 动态取色
学习          课表设置（当前作息摘要）
通知          提醒中心（总状态摘要）
隐私与数据     隐私与安全（解锁、防截屏、清除数据）
支持          帮助与常见问题 / 关于（版本号）
```

- 从 6 个分区收敛为 5 个，外观合并成一张卡（主题色 + 动态取色同属主题）。
- 「关于」从整张卡改成一行，版本号写在副标题里。
- 去掉设置里与「我的」重复的账号类内容（原本也没有），帮助 / 关于只在设置里出现。

### 提醒中心（按"什么时候提醒"分组）

```
系统通知未开启提示（按需）
总开关
课程与考试   上课提醒 / 考试提醒 / 评教截止
生活          低电费提醒 / 洗浴排队
学习通        作业提醒 / 通知提醒
免打扰        时段 + 开关
```

- 「成绩更新 · 暂不支持系统通知」不再以禁用开关出现（开关给不了反馈），改为「成绩」分组下一行说明文字。
