## 一、补考标记（小改动，独立于教室）

### 数据

有效成绩和原始成绩是两次独立请求（`MyCourseScore.action` 的 `type=1/0`），同一个 `kcdm` 在两边分数可能不同：

- 原始成绩 < 60（`GradeBand.Fail`）
- 有效成绩 ≥ 60（非 Fail）

满足即"补考通过"。

### 实现方式（不新增网络请求）

进成绩页时顺带读一次同 semester 的**原始成绩缓存**（`entities.read("jw.grades.$dm.0")`），
建 `courseCode -> GradeBand` 的映射；列表渲染时给有效成绩行的课名做一次查表。
缓存不存在就只是不显示标记——不在首屏额外发请求。

### 视觉

```
▍ 高等数学                    62
  3.0 学分 · 1.0 绩点 · 及格  [补考]
```

- 标签放在等级文字之后，`caption2Style()` 11dp，主色 12% 底、主色文字、4dp 圆角，左右 5dp 内边距。
- 不做红色：补考通过是结果，不是告警。
- 无障碍朗读："高等数学，62 分，及格，补考通过，3.0 学分"。

## 二、空闲教室：现状问题

| 现状 | 问题 |
|---|---|
| 日期只有「今天/明天/后天」三个 chip | 想查下周一查不到；文案也不告诉你"明天是周几" |
| 楼栋是一整行横滑 chip | 二十来栋楼要盲滑，找不到自己在哪栋 |
| 结果是一列"教室 · 空闲节数"的文字行 | 只知道"空闲 6 节"，不知道**哪几节**；要决定去哪间，还得自己数 |
| 没有"和我课表冲突"的概念 | 查到的空闲教室可能正好是我在上课的时间 |

---

## 三、目标

一句话：**能在 3 秒内回答"我这节课/下节课，去哪间空教室"**。

三个判断必须一屏可见：
1. 哪天、第几节 —— 顶部日期 + 节次表头；
2. 哪间、多大 —— 房间名 + 座位数；
3. 有没有空 —— 10 个方块，一眼扫完。

外加一个**筛选**：只想看"周四第 3、4 节、躬行楼"里能用的教室时，三个条件一组合，列表就只剩这些。

### 4.0 筛选栏（页面主控，一行三个条件）

```
‹  周四 11/19  ›   第 3·4 节 ✕   躬行楼(S2) ▾   [全部]
```

- **三个条件都可单独使用，也可组合；未设置即"不限"**：
  | 条件 | 默认 | 可选项 | 说明 |
  |---|---|---|---|
  | 日期 | 今天 | 今天起 30 天内 | 只能往后翻，不能看历史（教务只排未来） |
  | 节次 | 不限 | 1–10 节多选；带预设「上午 / 下午 / 晚上 / 全天」 | 选多个 = 这些节**同时**空闲才算符合 |
  | 楼栋 | 不限 | 全部楼栋 + 各校区楼栋 | 不选楼栋时跨楼栋查，结果按楼栋分组 |
- 已设置的条件显示为实心 chip（附一个 ✕ 直接清掉），未设置显示为描边 chip（"节次/楼栋"）。
- 三个条件都空时，就是"今天全楼所有教室的空闲情况"，和现在的浏览态一致。
- 日期两侧箭头保留「前一天/后一天」，但**左箭头到今天即止**，不给过去。

### 4.1 楼栋选择

- 条件是 chip，点开 `PrismSnapSheet`：第一项「全部楼栋」，下面按校区分组（惠济 / 中心…）。
- 选「全部楼栋」时结果分组标题变成楼栋名（见 4.7），单栋时分组标题是教室类型。
- 二十来栋楼放在可滚动 Sheet 里，比横滑 chip 好找；当前项置顶并打勾。

### 4.2 日期

- 中间日期可点，开 Material3 `DatePicker`，`selectableDates` 只允许 `[今天, 今天+30 天]`。
- 今天显示"今天 · 周四 11/19"，其他天显示"周五 11/20"；离开今天时右侧出现「回到今天」。
- 左箭头在今天就变灰禁用；右箭头到第 30 天禁用。

### 4.3 图例

- 四个状态，只渲染当前数据里出现过的：`空闲` `有课` `我的冲突` `临时活动`（后者无数据时不显示）。
- 图例是一行小方块 + 文字，`caption2Style()`，不占卡。

### 4.4 节次表头 + 房间行

- 表头：`1…10`，每格与下方方块同宽、居中对齐。
- 房间行：
  - 左列（约 60% 宽）：房间名 `bodyStyle()` 最多 2 行、类型在组头显示，座位数 `caption2Style()` 跟在名字后（"64 座"）。
  - 右列：10 个 `9dp × 9dp` 方块，间距 2dp，圆角 2dp。
- 分组：按 `jslxmc`（计算机房 / 丝网印刷实训室 / 木工模型实训室…）分组，组头 `SectionHeader` 风格但不带 action；组内按房间号升序。
- **两种行形态，由"节次"这个筛选条件决定**：

  | 条件 | 行样式 | 理由 |
  |---|---|---|
  | 节次 = 不限 | 房间名 + 座位数 + **10 个方块** | 浏览态，需要看全天占用 |
  | 节次 = 第 3·4 节 | 房间名 + 座位数 + **「第 3·4 节可用」**，**不画方块** | 列表里的房间已经全部满足条件，方块不再提供新信息，只是噪音 |

  筛选态的行更高一点（56dp → 64dp），名字允许两行，右侧一句 `caption2Style()` 的可用说明；
  左侧用 3dp 竖色标（`primary`）替代方块，保持"这一行是命中的"。
  切回"不限"时方块整体淡入 180ms，不做逐格动画。
- 桌面端（≥600dp）可用两列布局，本文先只做手机单列。

### 4.5 状态色（与参考图的差异）

参考图用红/绿/蓝三色。**我们不照抄**，理由：红绿是把"占用"当告警，实际占用是常态，整屏会红成一片。

| 状态 | 取色 | 说明 |
|---|---|---|
| 空闲 | `surfaceContainerLowest` + 1px `outlineVariant` 描边 | 白色小方块，靠描边立住 |
| 有课 | `onSurface` 28% 灰块 | 常态但要看得出"这节有课"，比首版的 14% 再深一档 |
| 我的冲突 | `primary` 实心 | 唯一需要我注意的：这间空着，但我在上课 |
| 临时活动 | `tertiary` 12% | 有数据才显示 |

已按你的反馈把「有课」加深到 28%。如果之后还觉得对比不够，这组值集中放在 `ClassroomCellStyle` 一处，改一个常量即可。

### 4.6 我的冲突怎么算

- 取当天日期的"周几"和"第几周"，用本地课表（`TimetableData`）筛出这一天我有哪些节次。
- 教室 `sfkx` 显示空闲、但我这一节有课 → 画成"我的冲突"。
- 拿不到当周课表（未绑定/未缓存）→ 不算冲突，图例里也不出现该项。

### 4.7 跨楼栋查询（楼栋=不限）

- 一栋楼一次 `getJsxx`，全部楼栋 = N 次请求。按 6 并发分批，顶部显示进度「已查 8/21 栋」。
- 每栋结果按 (楼栋, 日期) 进内存缓存，切回来不重复请求。
- 结果分组标题：楼栋名 → 教室类型；单栋查询时只有教室类型一层，避免层级忽深忽浅。
- 某栋返回空/超时不阻塞整体：失败楼栋在列表末尾合并成一行「3 栋未查询成功 · 重试」。

## 五、数据与接口

`POST getJsxx`（参数 `rq=yyyy-MM-dd`、`jxl=楼栋 dm`）→ `{result:{zdjc:"10", jsxx:[{jsmc,jsrl,jslxmc,sfkx}]}}`

| 字段 | 用途 |
|---|---|
| `jsmc` | 房间名（含前缀 S2-301） |
| `jsrl` | 座位数 |
| `jslxmc` | 分组（教室类型） |
| `sfkx` | 按节次的占用串；`1`=空闲，其余=占用 |
| `zdjc` | 最大节次，决定表头列数（默认 10） |

- 一次请求 = 一栋楼一天；切换楼栋/日期各自缓存（内存 LRU，8 条）。
- 预取：切到某天时顺手预取前一天/后一天，滑动更顺。
- `sfkx` 长度不足 `zdjc` 时，缺的节次按"未知"渲染（空心虚线方块），不猜成空闲。

## 六、状态

| 状态 | 表现 |
|---|---|
| 加载 | 表头先出，下面 3 行骨架（名字条 + 10 个灰方块） |
| 全天空闲 | 不铺 10 行白块，改成一句汇总卡："本楼 12 间教室今天全天空闲" + 「查看详情」展开 |
| 无教室 | "今天这栋楼没有排教室"（不说"暂无数据"） |
| 筛选无匹配 | "没有符合条件的教室" + 一句可操作的建议（"试试第 5-6 节或换栋楼"）+ 一键清空筛选 |
| 失败 | 错误说明 + 重试；未绑定时给"去教务登录" |
| 未绑定 | 说明 + 主按钮 |

## 七、动效（克制）

- 切日期：内容 `fadeThrough(90/210)`，**不做横向滑动**（避免和课表切周混淆）。
- 切楼栋：列表整体淡入 180ms。
- 方块不做逐格入场（一屏 100+ 个方块会变成烟花）。
- 点方块：只做 0.98 按压缩放 + 触感，弹出一行工具提示（"周四第 5 节 · 14:30–15:15 · 64 座"）。

## 九、已定的口径

1. **状态配色**：灰 = 有课（加深到 28%）、白 + 描边 = 空闲、主色 = 我的冲突；不用参考图的红/绿。
2. **日期范围**：只能往后翻，30 天内，不能看历史。
3. **点方块**：弹一行提示（周几第几节 · 起止时间 · 座位数），不跳转。
4. **补考标签**：小号标签（11dp、4dp 圆角、主色 12% 底）。
5. **筛选**：日期 / 节次 / 楼栋三个条件可单独也可组合，都空时等于浏览全天全楼。
6. **选了节次就不画方块**：列表已经全部命中，只留教室信息，避免一屏点阵噪声。

方案冻结，按第八节顺序开始实现。
